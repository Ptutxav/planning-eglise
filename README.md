\# GUIDE UTILISATEUR - GESTION DE PLANNING



\## 1. INSTALLATION

Cette application est "autonome". Il n'y a rien à installer.

\- Téléchargez le fichier `planning.html`.

\- Double-cliquez dessus pour l'ouvrir dans votre navigateur web (Chrome, Edge, Firefox).

\- Note : Une connexion internet est requise pour charger les styles et les icônes.



\## 2. FONCTIONNALITÉS CLÉS

\- \*\*Glisser-Déposer :\*\* Déplacez les personnes depuis la liste de gauche vers le planning, ou d'une case à l'autre.

\- \*\*Gestion Intelligente du Repos :\*\* Une ligne verte "EN REPOS" est disponible pour chaque événement.

\- \*\*Alertes Famille :\*\* Si vous placez un membre d'une famille en repos, une alerte rouge apparaît si un autre membre de cette même famille travaille le même jour.

\- \*\*Exception Conseil :\*\* Les membres du "Conseil" ne déclenchent pas d'alerte de repos et peuvent être placés plusieurs fois par événement.

\- \*\*Export PDF :\*\* Génération automatique d'un fichier PDF format A3 pour impression.



\## 3. UTILISATION PAS À PAS



A. GÉRER L'EFFECTIF (Colonne de gauche)

\- \*\*Ajouter :\*\* Utilisez le bouton "Ajouter une personne" en bas à gauche. Précisez le Nom, le Rôle et l'ID Famille (ex: "Dupont").

\- \*\*Modifier :\*\* Cliquez sur le petit crayon au survol d'une personne pour modifier ses infos.

\- \*\*Indicateurs :\*\* - Un badge rouge signale si une personne n'a aucun repos planifié sur la période affichée.

&nbsp; - Les membres du Conseil ont un badge violet.



B. CONSTRUIRE LE PLANNING (Tableau central)

\- \*\*Créer des événements :\*\* Cliquez sur le bouton "Événement" en haut à droite pour ajouter une colonne (ex: un nouveau Dimanche).

\- \*\*Renommer :\*\* Cliquez sur le titre d'un événement (ex: "Dim 05 Jan") pour le changer.

\- \*\*Placer les gens :\*\* Glissez les cartes depuis la gauche vers les cases.

\- \*\*Supprimer :\*\* Cliquez sur la croix (x) d'une carte pour l'enlever du planning.



C. EXPORT ET SAUVEGARDE

\- \*\*Reset Total :\*\* Le bouton "Reset Total" efface tout le tableau pour recommencer à zéro.

\- \*\*Export PDF :\*\* Cliquez sur "Exporter PDF". L'application va formater le tableau (en retirant les barres de défilement) et télécharger un fichier prêt à imprimer.



\## 4. ASTUCES

\- Pour qu'une alerte famille fonctionne, assurez-vous que les deux conjoints ont exactement le même "Nom de Famille" dans leur fiche.

\- Vous pouvez déplacer une personne directement d'un dimanche à un autre sans avoir à la supprimer.
